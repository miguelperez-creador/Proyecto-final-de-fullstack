🚀 Tecnologías Usadas
Python 3.x - Lenguaje de programación principal
Flask - Framework web ligero
MariaDB - Base de datos
HTML/CSS - Frontend
Bootstrap (opcional) - Estilos responsivos
📋 Características
✅ Creación de tickets de soporte
👥 Gestión de usuarios y roles
📊 Panel de control con estadísticas
🔍 Búsqueda y filtrado de tickets
💬 Sistema de comentarios
📈 Seguimiento de estados (Abierto, En Progreso, Cerrado)
🛠️ Instalación
Requisitos previos
Python 3.7 o superior
pip (gestor de paquetes de Python)
Pasos de instalación
Clona el repositorio
git clone https://github.com/miguelperez-creador/Proyecto-final-de-fullstack/blob/main/docs/manual_usuario.md
cd helpdesk-agosto-2025
Crea un entorno virtual (recomendado)
python -m venv venv

# En Windows
venv\Scripts\activate

# En macOS/Linux
source venv/bin/activate
Instala las dependencias
pip install -r requirements.txt
Ejecuta la aplicacións
# Windows
python app.py

# macOS/Linux
python3 app.py
Accede a la aplicación Abre tu navegador en: http://localhost:5000
