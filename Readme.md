# 🚀 Sistema Help Desk – Proyecto Full Stack

## 🖥️ Tecnologías Usadas

* **Python 3.x** – Lenguaje de programación principal
* **Flask** – Framework web ligero
* **MariaDB** – Base de datos
* **HTML / CSS** – Frontend
* **Bootstrap** – Estilos responsivos (opcional)

---

## 📋 Características

* ✅ Creación de tickets de soporte
* 👥 Gestión de usuarios y roles
* 📊 Panel de control con estadísticas
* 🔍 Búsqueda y filtrado de tickets
* 💬 Sistema de comentarios
* 📈 Seguimiento de estados (Abierto, En Progreso, Cerrado)

---

## 🛠️ Instalación

### Requisitos previos

* Python 3.7 o superior
* pip (gestor de paquetes de Python)

### Pasos de instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/miguelperez-creador/Proyecto-final-de-fullstack.git
cd Proyecto-final-de-fullstack
```

2. Crear un entorno virtual (recomendado):

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

3. Instalar dependencias:

```bash
pip install -r requirements.txt
```

4. Ejecutar la aplicación:

```bash
# Windows
python app.py


```

5. Abrir la aplicación en el navegador:  http://127.0.0.1:5000
